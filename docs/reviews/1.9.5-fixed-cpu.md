# Fixed CPU temperature source

The previous code selected the maximum temperature every sample (both SMC and HID), so changes could represent different thermal zones rather than one source. Version 1.9.5 preserves model priority, selects the first valid CPU channel and retains its identity. Intel package/diode candidates remain ahead of discovered per-core channels. SMC normal-path sampling stops after the selected valid temperature; other channels are probed only on failure. HID enumeration uses a stable performance-cluster/name order and the selected identity.

A selected source must fail three consecutive samples before a valid replacement is accepted. Transient failures yield no CPU temperature, keeping the other metrics. No smoothing or stale temperature is substituted. Valid fallback sources remain selected even if an earlier-priority source recovers. The Performance card identifies the source; CPU charts exclude other source identities and break at gaps.

Validation: source priority, hotter-secondary rejection, selected-channel-only reads, fallback recovery, invalid selected readings, three-failure hysteresis and unchanged power/fan data are covered by deterministic tests. Existing release Swift preflight suites passed. M2 Pro live readings and a rendered Performance page confirm the fixed-source label; intermittent invalid readings observed in live sampling motivated the three-failure policy. Universal build, package version/architecture/signature validation, daemon dry-run and uninstall tests passed. No physical verification on other Mac models is claimed.

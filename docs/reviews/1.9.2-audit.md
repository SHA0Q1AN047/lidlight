# Lidlight 1.9.2 bug audit

Scope: updater, quota parsing and request lifecycle, recovery notifications, session cancellation, performance sampling, process CPU accounting, countdown persistence, and existing sleep policy. This is a local maintenance build; no release was published by this audit.

| Finding | Fix | Regression coverage |
| --- | --- | --- |
| Switching release channels during a package download could still open the old-channel installer; the new channel was not rechecked. | Invalidate the captured release before installer handoff and recheck after the download finishes. | AppUpdaterTests: controlled download paused across a channel change. |
| A future persisted update-check timestamp could suppress automatic checks after clock correction. | Treat a timestamp ahead of the current clock as due for a new check. | AppUpdaterTests: tomorrow's persisted timestamp, automatic check enabled. |
| Cancelling presentation mode within the delayed activation interval could re-enable its display assertion. Delayed screen-off retries could also survive cancellation. | Session generations invalidate deferred work on stop, quit or manual mode change. Presentation activation also requires the session to remain active. | AuditRegressionTests: cancelled presentation sends no activation; uncancelled presentation still works. |
| Process watch could be saved even when starting its timer was rejected because another mode was pending. | Return success from timer start and register the watched process only on success. | AuditRegressionTests: owned child process, pending mode, no saved watch or command. |
| Disabling/re-enabling quota during a request could apply an obsolete response without fetching again. | Ignore old request generations; fetch again after the old request finishes if quota is enabled. | AuditRegressionTests: blocked fetch, toggle twice, verify a second request. |
| Boolean fields and fractional durations were accepted as numeric quota values; extreme reset timestamps could reach date formatting. | Reject booleans, require exact positive integer durations and bound reset dates. | AuditRegressionTests: boolean usage/duration/reset, fractional minutes and extreme date. |
| Changing quota window duration could leave old exhaustion evidence armed indefinitely. | Reset incompatible evidence without announcing recovery; track exhaustion under the new window. | AuditRegressionTests: changed duration, subsequent exhaustion and recovery. |
| Moving the clock backward could stop sensor refreshes and retain points dated in the future. | Resume immediately after correction; prune future history. Quota polling now uses monotonic uptime. | AuditRegressionTests: backward clock and quota polling interval. |
| Reopening Performance within six seconds could include hidden time in process CPU percentages. | Reset process counters when the page is hidden or sampling is disabled; suppress stale in-flight rankings. | AuditRegressionTests: leave/reopen and require a new baseline. |

Efficiency changes:

- Read SMC sensors only while home or Performance is visible and displays are awake.
- Do not publish redundant empty process state on every hidden tick.
- Animation frames update the cached cat image without rebuilding tooltip strings at animation frequency.
- Update menu-bar title only when its text changes.

Validation uses isolated preferences, mocked updater downloads and injected session commands. Daemon tests use dry-run mode and uninstall tests mock system commands. Hardware support and macOS permission behavior still vary; this audit does not claim every runtime path or every supported Mac was exercised.

## Completed verification

All 16 test programs/suites passed: updater, quota weather, performance, menu cat, prior improvements, assistant features, day countdown, quota parser, feature state, audit regressions, power policy, diagnostics, quit controller, CLI, daemon dry-run and mocked uninstall. The 1.9.2 package was expanded and its version, arm64/x86_64 executable and app/helper signatures verified. Its native executable also completed diagnostics mode successfully. Menu-bar interaction, installation and publication were not performed for this build.

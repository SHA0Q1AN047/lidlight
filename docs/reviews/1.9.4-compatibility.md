# 1.9.4 Mac compatibility

Independent read-only implementation; no Stats implementation or external library bundled. Hardware protocol/key references:
- https://github.com/exelban/stats/blob/master/SMC/smc.swift (enumeration command 8, index field and key count)
- https://github.com/exelban/stats/blob/master/Modules/Sensors/values.swift (Intel core/package channels and GPU exclusion)
- https://github.com/exelban/stats (macOS minimum and sensor-key support limitations)

Changes: enumerate Intel CPU candidates with strict classification, support signed fixed-point SMC formats, enable named CPU HID fallback on all Apple Silicon, periodically recreate optional HID clients, reconnect failed SMC connections with cooldown, and hide fan metrics on known 12-inch Intel MacBooks. Exact chip-family matching avoids M10 being mistaken for M1. Enumeration is bounded to 16384 entries and runs only at discovery/recovery, on the background sensor queue; Apple Silicon skips the unnecessary inventory scan. Missing keys are retried after 60 seconds; value reads still occur on the existing two-second interval. Reads stop with the closed panel. Read-only commands only, no fan writes or new authorization.

Validation:
- All release preflight suites passed, including malformed inventory bounds/replies, Intel dual-package selection, GPU/battery exclusion, signed formats, fanless models, future chip matching and existing asynchronous regressions.
- Live M2 Pro power, CPU temperature and both fan readings passed.
- Live enumeration exposed 2285 keys and correctly decoded #KEY, FNum and PSTR. The temporary test build exposes only the private inventory method to the test harness; packet implementation is unchanged.
- Universal arm64/x86_64 build and strict app signature verification passed; macOS deployment target remains 12.0.

Limits: No physical Intel, M1, M3/M4/M5, Air, mini, iMac, Studio or Pro validation is claimed. Named CPU HID services are optional. Unknown SoC keys remain unclassified; device-reported whole-system power is not replaced with battery discharge or CPU/GPU estimates. Supporting an OS/architecture does not guarantee every sensor exists on every model.

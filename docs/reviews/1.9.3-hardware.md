# 1.9.3 hardware and glass fixes

- Hide fan summary column and detail card for confirmed fanless machines. The remaining home metrics share the available width.
- Recognize Apple-silicon MacBook Air model identifiers even when AppleSMC cannot report FNum. Never infer fanlessness merely from an unreadable sensor or stopped fans; cache positive fan topology across temporary read failures.
- Add optional M1 CPU HID thermal fallback, independent of the AppleSMC connection. Read only CPU pACC/eACC temperature services; do not substitute GPU, battery or ambiguous die readings. Keep valid SMC values primary and filter invalid fallback samples. Missing runtime symbols or restricted service access result in unavailable readings, with no authorization escalation.
- Restore M2 performance-cluster candidates, add Intel CPU diode/proximity candidates, and correct the M5 Tp0O candidate spelling.
- Use clear Liquid Glass for content cards on macOS 26, reduce panel tint/blur opacity, and remove the popover window's solid background. Preserve opaque surfaces with Reduce Transparency.

Reference facts (no third-party implementation was imported):

- Apple MacBook Air model identifiers: https://support.apple.com/en-mide/102869
- M1 fanless Air design: https://www.apple.com/ca/newsroom/2020/11/introducing-the-next-generation-of-mac/
- CPU SMC channel names: https://github.com/exelban/stats/blob/master/Modules/CPU/readers.swift
- Read-only M1 CPU HID service ABI and CPU product prefixes: https://chromium.googlesource.com/chromium/src/+/112.0.5615.165/components/power_metrics/m1_sensors_mac.mm

Validation: hardware tests cover known fanless/unknown/stopped-fan cases, primary/fallback precedence, invalid temperatures and CPU-only service filtering. Fanless home and detail layouts were rendered with fixture data and opaque accessibility surfaces. The available machine is M2 Pro; its SMC readings passed live checks and the optional HID interface safely returned no supported CPU service. M1 fallback still requires verification on an affected M1 machine. Transparent compositing depends on the actual desktop background and cannot be judged from these opaque layout renders.

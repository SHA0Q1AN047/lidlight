## MagSafe activity light improvements

- Detect local Codex activity through macOS file-change notifications, with a 30-second fallback check and a lightweight service heartbeat.
- Pulse amber for two seconds on and two seconds off while Codex works. This is a slow blink, not brightness fading.
- Keep activity visible during night mode or manual idle-off. When work ends, turn the light off if either darkness setting applies; otherwise return to green.
- Fix irregular blinking caused by repeated heartbeats, improve LED writes and system handoff, and tolerate brief firmware resets.

Validated with activity, filesystem-event, LED policy, and release regression tests. Actual response time depends on Codex writing local events and macOS delivering notifications; battery savings have not been measured.

LED control requires compatible MagSafe 3 hardware. Remote/cloud activity without local session events is not detected. This installer is unsigned and not Apple notarized.

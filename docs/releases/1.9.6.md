# Lidlight 1.9.6

A clearer glass dashboard with much less opaque fill.

- Replace the opaque system popover shell with a transparent, rounded anchored panel.
- Use one light background material, near-clear content cards and fine reflective borders.
- Retain native Liquid Glass controls on macOS 26 and standard material controls on older supported systems.
- Preserve keyboard input, Escape/outside-click dismissal and on-screen placement across displays.
- Keep opaque surfaces when Reduce Transparency is enabled. No system appearance setting is changed.

CPU fixed-source behavior from 1.9.5 is preserved. macOS 12 or newer; universal Intel/Apple Silicon package.

The app is ad-hoc signed; the installer is unsigned and not Apple-notarized.

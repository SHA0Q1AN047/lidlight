## What's new

- A redesigned dashboard with clearer power controls, quota weather and live performance cards.
- More transparent native Liquid Glass on macOS 26, with lavender, mist-blue and peach accents that adapt to light and dark mode.
- A pixel cat in the menu bar: CPU activity controls its walking/running pace, and sustained high system thermal pressure adds a sweating animation.
- Codex account quota, reset countdowns and local usage trends. Optional recovery notifications wait for a successful check confirming availability.
- Live device-reported system power, supported CPU temperature sensors and fan RPM, plus two-minute charts and the top three readable CPU processes.
- A supply check that warns about sustained battery loss while connected to AC power.
- A day countdown: choose an event name and date under Settings or Sessions. It appears in the menu bar only when an event is saved; Remove countdown hides it.
- In-app GitHub updates with package size and SHA-256 verification, plus app/background-service version confirmation after installation.

## Fixes and efficiency

- Temperature labels stay on one line, with separate units in the detailed view.
- Suspect low-temperature samples are shown as unavailable; sensor availability is retried each sample instead of waiting a minute.
- Partial quota responses cannot incorrectly announce quota recovery.
- Sensor reads stop when the panel closes; CPU-process scans only run on the Performance page. Screen sleep pauses the cat animation and quota/update checks.
- Existing sleep modes, sessions, rules and preferences are preserved during upgrades.

## Download and install

Download **Lidlight.pkg** below and run the installer. Administrator approval is required for the background service. This universal build supports Apple silicon and Intel on macOS 12 or later; native Liquid Glass requires macOS 26. Hardware sensor availability varies by Mac.

Codex quota requires an installed, signed-in Codex CLI or supported Codex desktop app. Quota recovery notifications are opt-in on the Codex quota page.

This package is not Apple-notarized and its app uses ad-hoc signing. macOS may require manual approval before installation or opening.

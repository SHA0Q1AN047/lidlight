## Hardware compatibility

- Fanless machines now hide the fan column and fan detail card. The remaining home metrics share the available space.
- Recognize Apple-silicon MacBook Air models even when SMC cannot return a fan count. A stopped fan or a failed read on a fan-equipped Mac is not treated as fanless.
- Add an optional read-only M1 CPU HID temperature fallback when SMC has no valid CPU reading. Only CPU-specific thermal services are accepted; battery, GPU and ambiguous die readings are not substituted.
- Restore M2 performance-cluster temperature candidates, add Intel CPU fallback candidates and correct an M5 sensor-key spelling.

## Appearance

- Clearer Liquid Glass content cards on macOS 26, lighter background tint and reduced panel blur opacity.
- Remove the popover window's solid background. Reduce Transparency still uses opaque surfaces for readability.

## Validation and limitations

Hardware regressions and the complete local release test suite passed. Fanless layouts were checked with fixture data; live SMC readings were checked on M2 Pro. **The new M1 HID fallback still needs confirmation on an affected M1 Mac.** If macOS does not expose a supported sensor, temperature remains unavailable rather than showing an unrelated or invented value.

Download **Lidlight.pkg** below. Administrator approval is required for the background service. Preferences are preserved. This app uses ad-hoc signing and is not Apple-notarized; macOS may require manual approval.

## MagSafe Codex status light

- New **Power controls → MagSafe status light** controls, disabled by default.
- Local Codex tasks: blinking amber while running; green when idle. Unknown activity returns the light to macOS.
- Night lights off with a customizable local-time schedule (default 23:00–07:00), plus an immediate lights-off switch. Darkness takes priority over activity.
- Detects resumed conversations in older session folders and concurrent local sessions.
- Restores system LED control after app heartbeat loss, service shutdown, sleep or uninstall. LED writes are limited to the ACLC key and do not change battery charging controls.
- Fixes installer generation on macOS versions whose component analysis omits the relocatable field.

### Compatibility and limitations

Requires compatible Apple Silicon MagSafe 3 hardware and a connected MagSafe cable. Keep Lidlight running. Remote/cloud tasks without local Codex logs are not detected. New session discovery can take up to 30 seconds; existing session updates are checked every five seconds. Sleep returns LED control to macOS, so nighttime darkness while asleep is not guaranteed. With the feature active, colors indicate Codex activity rather than charging status. Other utilities controlling the same LED may conflict.

Software tests and universal arm64/x86_64 builds pass. A read-only ACLC probe succeeded on the development Mac; physical LED behavior across hardware models has not been verified.

### Installation

Download **Lidlight.pkg**, or use Lidlight's built-in updater. The app is ad-hoc signed; the installer is unsigned and is not Apple notarized. Installation requires administrator authorization.

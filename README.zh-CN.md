# Lidlight

讓 MacBook 合蓋後繼續運作的 macOS 選單列工具。介面使用英文。macOS 26 的操作與導覽元件使用原生 Liquid Glass，資訊區使用半透明材質；外觀跟隨系統淺色／深色模式，開啟「降低透明度」時改為實心介面。macOS 12–15 使用標準材質。建置需要 macOS 26 SDK。

- Automatic：插電時保持運作，電池供電時允許睡眠。
- Stay awake：電池供電時也保持運作；10% 低電量時允許睡眠。
- Allow sleep：恢復正常睡眠。
- 合蓋熄背光、同面板診斷與安全退出。

支援 macOS 12 以上與 Apple silicon / Intel。從本儲存庫 Releases 下載 Lidlight.pkg。此版本未有正式開發者簽章或 Apple 公證，macOS 可能阻擋安裝。請依自己的硬體驗證合蓋、拔電與背光恢復。

建置與測試方式見 [English README](README.md)。

Lidlight 是作者的原創 macOS 工具。

## 1.1 功能

- 定時清醒、自訂截止時間、單次清醒、簡報模式與等待程序完成。
- 指定 App、外接螢幕、每日／平日跨午夜排程規則。
- 可調低電量門檻、僅插電清醒、選擇性低電量通知。
- 全域快捷鍵、登入啟動、重啟模式、選單倒數與像素角色表情。
- 狀態原因、後續動作、最近 40 筆本機紀錄與電量下降估算。
- 關閉螢幕、鎖定繼續運作、恢復背光與背景服務復原。
- 可在 macOS「捷徑」的 Run Shell Script 呼叫 `/usr/local/bin/lidlight timer 60`。

手動 Allow sleep 暫停規則，Automatic 恢復規則；低電量與僅插電保護永遠優先。
App／程序／排程規則需要 Lidlight 持續執行；定時截止由服務執行。程序等待最多七天，避免程序無法追蹤時無限清醒。關閉螢幕依 macOS 設定可能鎖定；Lock & run 明確鎖定。通知啟用時才請求權限，預設不主動改變現有工作流程。

主頁額度顯示重置倒數；點電源狀態卡即可切換模式。性能卡加入兩分鐘迷你趨勢，關閉面板即停止感測器讀取。小貓提示顯示走路／跑步、CPU 用量與流汗原因；螢幕休眠時停止動畫並暫停額度與版本檢查。

## App 內更新

「Settings → Updates」可手動或每六小時自動檢查 GitHub Releases；有新版時主頁會顯示提示。預覽版需自行開啟接收。按 Download & update 後會下載 `Lidlight.pkg`、驗證大小與 GitHub 的 SHA-256 摘要，再開啟 macOS 安裝程式；需要管理員授權，設定會保留。舊版沒有更新功能的使用者需先手動安裝這次版本。

發布下一版時，調高 `VERSION`（例如 `1.3.1`），在 `main` 提交變更後執行 `bash scripts/release.sh`。腳本會測試、建置並發布正式 GitHub Release，自動附上 `Lidlight.pkg`；只推送程式碼或 tag 不會發送更新。現有 Release 不會被覆蓋。

## 額度天氣

主頁的 5 小時與每週額度各有像素天氣圖示，保留百分比：50% 以上晴天、20–49% 多雲、低於 20% 夕陽，真正用盡時顯示睡眠月亮。天氣門檻依畫面四捨五入後的百分比判斷；不足 1% 且尚未用盡時顯示 `<1%`。摘要以較緊的額度為準。讀取失敗或超過 15 分鐘未更新會顯示問號雲與快取標示；過了重置時間會等待新資料，不會自行假設補滿。不額外增加網路檢查或動畫計時器。

## 性能監視器

主頁直接顯示系統即時功耗 W、CPU 最高可用感測溫度與風扇最高 RPM。Performance 頁可查看每顆風扇與最近兩分鐘曲線。只在面板開啟時，於背景約每兩秒讀取；關閉即暫停，紀錄僅存記憶體，最多 60 筆。超過六秒未更新的數字不會繼續當作即時值顯示。

使用唯讀 AppleSMC 感測資料，不調整風扇，不啟動 powermetrics。系統功耗是硬體回報值，不是插座電表讀值；CPU 溫度是可用 CPU 感測器的最高值。風扇停轉顯示 0 RPM；只有控制器明確回報零顆風扇，才顯示無風扇。無法取得的資料顯示 Unavailable。已於 macOS 26.1 的 M2 Pro MacBook Pro 實測取得功耗、溫度與兩顆風扇讀值；其他機型的支援依硬體與系統限制而異。

## CPU 跑步小貓

選單列圖示改為六格像素小貓，整體 CPU 使用率低於 10% 時以每秒兩格慢走，負載升高逐漸加速，最高每秒 12 格。每秒讀一次核心 CPU 計數器並平滑速度，滑鼠移上去會顯示 CPU 百分比。圖片預先快取，深淺色選單列自動適配，低電量警示保留。

可在 Settings 關閉 Animate menu cat；系統「減少動態效果」也會停用動畫。螢幕休眠時停止動畫及 CPU 採樣，喚醒後重新取樣。SMC 功耗／溫度／風扇監視仍只在面板開啟時採樣。不需要額外權限、網路或外部指令。

## 主頁、熱壓力與更新確認

主頁保留額度天氣、用量趨勢與性能，模式及背光控制移入 Controls。小貓在 macOS 持續回報 serious／critical 熱壓力 15 秒後冒汗，恢復時清除；不使用固定 CPU 溫度門檻。

更新頁分別顯示執行中 App、磁碟上的 App 與運作中的背景服務版本。僅在三者相同且服務運作時確認更新成功；背景服務回覆本次隨機檢查碼並寫入 root 版本紀錄，App 會核對檢查碼、檔案權限與即時執行路徑，避免舊紀錄誤判。舊服務沒有紀錄時顯示未驗證，開啟安裝程式不等於更新成功。

額度歷史只保留本機最近 24 小時、最多 600 筆。至少三次讀值、跨越十分鐘且屬於同一個重置區間，才顯示已觀察到的用量速度；讀值下降、重置、超過十五分鐘的間隔或資料過期會中斷趨勢。不預測精確用盡時間，可在額度頁清除紀錄。

主頁／Controls 新增插電掉電檢查：持續插電 3–5 分鐘下降至少 2 個百分點才提醒，休眠、拔電或電量上升會重新觀察，不將充電上限誤判為供電不足。Performance 顯示可讀取的 CPU 前三名程序，100% 代表一核心，僅停留該頁時掃描。額度頁可開啟恢復通知；只有成功查詢確認所有已觀察額度恢復可用才通知，不依倒數推測。溫度超出保守的 10–130°C 顯示範圍時標示無法讀取，每次採樣重試。

倒數日：Settings → Day countdown（Sessions 也有入口），輸入事件名稱與日期後按 Save to menu bar。沒有儲存事件時不顯示，Remove countdown 可移除；當天顯示 Today，過去日期顯示已過天數，按本地日曆計算並保留至下次啟動。

## Mac 相容性

安裝包同時包含 Intel 與 Apple Silicon 版本，最低需要 macOS 12，適用於符合系統版本的 MacBook、Air／Pro、Mac mini、iMac、Mac Studio 與 Mac Pro。Intel 會列舉控制器中的 CPU 核心與雙處理器溫度通道；Apple Silicon 使用 M1–M5 對照，並在沒有有效讀值時嘗試 CPU 專屬 HID 溫度服務。連線失效會自動重試，已知無風扇機型（含 12 吋 Intel MacBook）隱藏風扇區塊。

目前只有 M2 Pro 實機完成即時讀值驗證，其餘機型通過編譯與模擬資料測試，仍需實機確認。不同 Mac 暴露的感測器不同，不能保證所有機型都有系統瓦數或 CPU 溫度；讀不到就顯示無法取得，不會拿電池／GPU 溫度或局部功耗代替。

CPU 溫度固定使用依機型優先順序選定的感測器，只在連續三次讀值失效時改用其他有效來源；不再每次取最高溫。Performance 會顯示目前來源，切換來源時不連接不同來源的趨勢線。正常路徑只讀選定的 SMC 溫度通道，數值保留真實變化，不額外平滑或保留失效讀值。
